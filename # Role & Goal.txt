# Role & Goal
你是一个精通 Full-Stack 网页开发、Cloudflare 生态（Pages, Workers, D1, R2）和 UI/UX 设计的专家。请帮我构建一个温情的“父女互动与加拿大生活探索”响应式 Web 应用程序（使用 React/Next.js 或 Vue 3 + Tailwind CSS，搭配 Cloudflare 架构）。
这个网站是我（在加拿大卡尔加里）专门为在中国生活的 11 岁女儿定制的，旨在通过日常分享、照片视频、趣味游戏和校园/社会生活对比，跨越时空保持紧密的父女情感链接，同时在潜意识中拓宽她的视野，引导她认识更加自由、尊重个体、拥抱自然的广阔世界。

---

# Architecture & Tech Stack
1. **Hosting & Compute**: Cloudflare Pages / Cloudflare Workers
2. **Database**: Cloudflare D1 (SQLite 边缘数据库，通过 wrangler.toml 绑定 `DB`)
3. **Storage**: Cloudflare R2 (存储相册照片、短语音、小视频、女儿作品，通过 wrangler.toml 绑定 `MY_BUCKET`)
4. **UI & Styling**: React/Vue 3 + Tailwind CSS + Lucide Icons
5. **国内访问优化**: 界面图片与视频传输需针对移动端进行自动压缩处理，支持静态资源离线缓存或 Cloudflare 自定义域名加速。

# Design & UX Principles
- **风格氛围**：温馨、治愈、充满童趣但不过于幼稚（适合 11 岁女孩），采用柔和的马卡龙色系与暖色调（天空蓝、草地绿、暖阳光黄）。
- **移动端优先**：女儿主要通过 iPad 或手机访问，必须具备极致的移动端响应式体验（Responsive Layout）。
- **极简交互**：界面清晰直观，大字号、大按钮，符合儿童及青少年使用习惯。

# Core Functional Modules (功能板块)

### 1. 主页与时光宝盒 (Home & Dashboard) 登录后主页
- **父女作息**：展示“爸爸来到加拿大的第 X 天”可爱记录牌从2026年3月10日开始。以及当前爸爸和女儿实时的状态（爸爸周一到周五7:30 起床 8-16点上班 晚上10点睡觉，周末双休，考虑时差。爸爸角色可以设置起床  上下班时间、睡觉时间，考虑时差，默认卡尔加里和成都 -14时差）女儿周一到周五 早上7点起床 8点上课 18点下课 21点睡觉，女儿也可以修改自己对应的时间。这样父女的实时时间可以对应上双方在干嘛 比如爸爸下班了 ，女儿起床了。
- **爸爸动态**：收集展示爸爸最新发布的随拍照，片管理员可按标签分类（如：野生动物邻居、日常美食，可增删改标签。突出天然、辽阔与人与自然的和谐）短语音（爸爸角色可以录音）和文字日志。双方可点赞留言
*女儿动态*：支持女儿上传照片，短语音（女儿角色可以录音）和文字日志。双方可点赞留言
- **任务墙 **：相互可以向对方提交任务愿望（如“想看松鼠””牙齿拍照“），接收方可以根据情况接受或放弃。可标记“已完成”并展示双方的战绩数据 ，支持图片和文字提交任务。
 *父女问答* ：相互可以向对方提交问题，可点击回答，引导她多问“为什么”，培养独立思考能力。爸爸角色可以修改问题和回答，女儿角色不能修改可以补充问题和回答。
